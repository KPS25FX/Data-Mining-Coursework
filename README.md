# Data Mining and Machine Learning coursework (COC131)

Loughborough University, Computer Science and Artificial Intelligence, 2025–26. Submitted April 2026.

An analysis of a census dataset in five parts: preprocessing and exploratory analysis, income fairness
(t-tests with Cohen's d), and the remaining modelling tasks, written up as a report.

- `notebooks/`: the Jupyter notebooks for Parts 1–5, the report, and the combined notebook
- `html/`: the same notebooks exported to HTML, readable in a browser without Python
- `report-part1.pdf`: the written report for Parts 1 and 2

The assignment brief and marking rubric belong to the university and are not included.
